Privacy Policy

Hidden Machinery and Hidden Machinery Studio · effective 9 October 2026

Who we are

Hidden Machinery is an independent studio making animated computer-science explainers, published on our YouTube channel Hidden Machinery Lab. Hidden Machinery Studio is our private publishing tool. It runs only on our own computer and is used only by us; it has no public users and no sign-up.

YouTube API Services

Hidden Machinery Studio uses the YouTube API Services to upload videos we made to our own YouTube channel, to set their thumbnails and captions, and to read our own channel's name and ID so it uploads to the right channel. Google's handling of data is described in the Google Privacy Policy, and use of YouTube is governed by the YouTube Terms of Service.

What information we access, store and use

  • Google sign-in token for our own account. When we sign Hidden Machinery Studio in to our channel, Google gives it an access token. We store it only in a private file on our own computer and use it only to make the calls described above. It is never shared, sold or sent anywhere except to Google.
  • Our own channel's name and ID, read from YouTube to check the upload destination.
  • The IDs and links of the videos we upload, kept in our project files so we can find them.

Hidden Machinery Studio does not access other people's accounts, and it does not collect, store or share any information about viewers.

This website

This website is a set of static pages. It uses no cookies, analytics, ads or trackers, and it collects no personal information. It is hosted by GitHub Pages, whose own logs are described in the GitHub Privacy Statement.

Keeping and deleting data

We keep the sign-in token only while we publish with Hidden Machinery Studio, and we delete it from our computer when we stop. Access can be revoked at any time on the Google security settings page; a revoked token no longer works and we delete our copy of it within 7 days.

Changes

If this policy changes, we will update this page and its effective date.
